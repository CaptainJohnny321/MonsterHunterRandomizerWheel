# Monster Hunter Wilds monster icons

This folder contains 31 large-monster icons converted to 512x512 RGBA PNG files for app use. Load `manifest.json` to enumerate the assets; each `file` path is relative to this folder.

## Source and attribution

Source files were downloaded from the [Monster Hunter Wiki MHWilds Monster Icons category](https://www.monsterhunterwiki.org/wiki/Category:MHWilds_Monster_Icons), which is published under [CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/) unless otherwise noted. The artwork and Monster Hunter names are property of their respective rights holders. Check the source file page before publishing a commercial app and retain any required attribution.

The original WebP files are preserved in `source/`; app-ready PNGs are in `png/`.
