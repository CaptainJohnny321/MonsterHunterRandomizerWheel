# Monster Hunter Wilds weapon icons

This folder contains the 14 playable weapon-class base icons converted to 512x512 RGBA PNG files for app use. Load `manifest.json` to enumerate the assets; each `file` path is relative to this folder.

## Source and attribution

Source files were downloaded from the [Monster Hunter Wiki MHWilds Equipment Icons category](https://www.monsterhunterwiki.org/wiki/Category:MHWilds_Equipment_Icons), which is published under [CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/) unless otherwise noted. The original WebP files are preserved in `source/`; app-ready PNGs are in `png/`.
